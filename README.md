# Follow-up Engine

## Problem

Sales follow-ups are often missed, delayed, or forgotten, causing otherwise viable opportunities to disappear.

## What It Does

The Follow-up Engine tracks prospect follow-up state, identifies actions that are due, drafts follow-up messages inside the original email thread, and stops the sequence when a reply is detected.

## Human Approval

AI drafts the message, but a person reviews and sends every message.

## Failure Handling

Known failure modes will include replies after draft creation, unsent drafts, out-of-office replies, bounces, unsubscribe requests, colleague replies, new-thread replies, time-zone issues, duplicate processing, and API failures.

## Configuration

The sequence cadence, stages and other behavior will be configuration-driven.
